Configuração de E-mail

Configure o serviço de envio de e-mails para recuperação de senha e lembretes de consulta.

EmailJS é a opção recomendada para projetos front-end. Crie uma conta gratuita e obtenha suas chaves.

📋 Como configurar no EmailJS:
  1. Crie uma conta em emailjs.com
  2. Conecte um serviço de e-mail (Gmail, Outlook, etc.)
  3. Crie um template de e-mail com as variáveis: {{to_email}}, {{to_name}}, {{subject}}, {{message}}, {{html_message}}
  4. Copie o Service ID, Template ID e Public Key para os campos acima

SMTP requer um backend rodando. Configure também o BACKEND_URL.

📋 Gmail App Password: 1. Ative 2FA em: https://myaccount.google.com/security 2. Gere App Password em: https://myaccount.google.com/apppasswords 3. Use o App Password gerado no campo SMTP Password SMTP_HOST=smtp.gmail.com | SMTP_PORT=587 | SMTP_SECURE=false

SendGrid — Crie uma conta em sendgrid.com e gere uma API Key.

Mailgun — Crie uma conta em mailgun.com.

Resend — Crie uma conta em resend.com.
